# NIL Valuation - 4 Week Sprint Plan

## WEEK 1: Data & Core Model (This Week)
**Goal:** Build valuation algorithm with existing data

### Tasks:
- [ ] Create valuation model module (`src/valuation/model.py`)
- [ ] Define scoring functions:
  - `normalize_performance_score()` - Convert yards/TDs to 0-100 scale
  - `normalize_social_score()` - (placeholder: use recruiting_stars for now)
  - `get_position_multiplier()` - QB (1.5x), RB (1.0x), WR (1.2x), etc.
  - `get_conference_multiplier()` - SEC (1.3x), Big Ten (1.2x), ACC (1.0x), Big 12 (0.9x)
  - `calculate_nil_value()` - Final formula
- [ ] Create test cases to verify formulas
- [ ] Validate with a few known players

**Deliverable:** Working valuation function that takes player ID → returns estimated NIL value

---

## WEEK 2: API Endpoints
**Goal:** Expose valuation to users via REST API

### Tasks:
- [ ] Install FastAPI: `pip install fastapi uvicorn`
- [ ] Create `src/api/` directory
- [ ] Build endpoints:
  - `GET /api/players/{id}` - Player details + valuation
  - `GET /api/valuations/top` - Top 50 valued players
  - `GET /api/players/search?q=name` - Search players
  - `GET /api/school/{school}` - Top players by school
  - `GET /api/position/{position}` - Top players by position
- [ ] Add request validation with Pydantic
- [ ] Create API documentation (auto-generated by FastAPI)
- [ ] Test endpoints locally

**Deliverable:** Working API you can call with curl/Postman
